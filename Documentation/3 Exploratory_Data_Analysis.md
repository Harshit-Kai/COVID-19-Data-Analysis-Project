# Exploratory Data Analysis (EDA)

The analysis focused on understanding the global impact of COVID-19 using SQL queries and data visualization techniques.

The following analyzes were performed:

- Total Cases vs Total Deaths
- Total Cases vs Population
- Countries with Highest Infection Rate
- Countries with Highest Death Count
- Continent-wise Death Analysis
- Global COVID-19 Statistics
- Vaccination Progress Analysis

Key Insights:

- Europe recorded the highest cumulative death count.
- Infection rates varied significantly across countries.
- Population size influenced total cases and deaths.
- Multiple waves of COVID-19 infections were observed globally.
- Vaccination programs expanded rapidly across many countries.
- Significant differences existed in infection and mortality rates between regions.

SQL Techniques Used:

- Aggregate Functions (SUM, MAX)
- GROUP BY
- ORDER BY
- JOINS
- Common Table Expressions (CTEs)
- Window Functions
- Views

Outcome:

The findings from the exploratory analysis were used to build an interactive Tableau dashboard that highlights global COVID-19 trends, death statistics, infection rates, and geographic comparisons.
